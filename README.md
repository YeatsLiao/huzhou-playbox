# 湖州创意互动小游戏集合

这是一个包含多款融入了湖州文化元素的创意互动小游戏的 React 网页项目。通过有趣的游戏体验，让玩家在娱乐中了解和探索湖州。

## 🎮 游戏列表

1. **太湖捕鱼 (Fishing Game)**
   - **玩法**：在60秒的限时内点击屏幕上的鱼群进行捕获，鱼竿和渔网两种工具可供切换，考验玩家的反应速度。
   - **特色**：模拟太湖渔民文化。

2. **莫干山竹林探险 (Maze Game)**
   - **玩法**：通过方向键、WASD 或移动端虚拟方向键控制角色，在随机生成的竹林迷宫中寻找出口，挑战最快完成时间。
   - **特色**：展现莫干山竹林风貌。

3. **湖笔书法挑战 (Calligraphy Game)**
   - **玩法**：在屏幕上模拟使用毛笔书写汉字（如阮元《吴兴杂诗》中的汉字），系统会根据你的书写覆盖率给出评分，支持保存你的书法作品。
   - **特色**：致敬中国毛笔之首——湖笔文化。

## 💻 本地开发

### 依赖安装

```bash
npm install
```

### 启动开发服务器

```bash
npm run dev
```

### 构建生产版本

```bash
npm run build
```

## 🚀 自动部署到 GitHub Pages

本项目已经配置了现代化的 **GitHub Actions** 自动化部署流程，实现了一次配置，终身自动部署。

### 如何触发部署？

只要你将代码推送到 `main` 分支，GitHub Actions 就会自动启动构建流程，并将产物部署到 GitHub Pages 上：

```bash
git add .
git commit -m "你的更新说明"
git push origin main
```

*(就是这么简单，完全不需要在本地运行任何构建或部署命令！)*

### 首次配置指南

如果是第一次克隆本项目或者刚开启 GitHub Pages，请确保在仓库设置中完成以下配置：

1. 进入你的 GitHub 仓库主页。
2. 点击顶部的 **Settings** 标签页。
3. 在左侧菜单栏中找到 **Pages** 选项。
4. 在 **Build and deployment** 下的 **Source** 下拉菜单中，选择 **`GitHub Actions`**。

完成以上设置后，下一次推送到 `main` 分支时，页面就会自动上线！
